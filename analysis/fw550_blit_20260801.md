The probe creates an 8×8 host-visible RGBA8 transfer-source image and a 20×20
host-visible RGBA8 transfer-destination image. A nearest-filtered Vulkan blit

match all 256 scaled pixels and retain the 144 guard pixels outside the
rectangle. The source and destination deliberately omit sampled and color-
attachment Vulkan usage; those capabilities are private implementation detail
of the graphics-meta path and Vulkan command validation still requires the
declared transfer usages.
