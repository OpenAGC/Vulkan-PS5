# FW 5.50 BC image/mip-copy qualification (2026-08-01)

## Scope

The bounded `vulkan_ps5_bc_copy_probe` exercises `vkCmdCopyImage` for all
fourteen advertised BC1-BC7 UNORM, SNORM, SRGB, UFLOAT, and SFLOAT formats.
For every format it creates an 8x8 two-mip source and a 16x16 three-mip
destination in mapped linear memory, fills source blocks with deterministic
format/mip/block-specific bytes, and initializes the destination to a sentinel.

One command buffer transitions all resources and records two copies per
format:

- source mip 0 (8x8, four blocks) to destination mip 1;
- source mip 1 (4x4, one block) to destination mip 2.

After a host-read transition and a Vulkan fence with a two-second upper bound,
the probe compares every copied block byte and verifies that destination mip 0
still contains its sentinel. This proves block-aware image-region copies,
queried nonzero-mip layouts, copy-state transitions, and row-address emission
through public OpenAGC `agcCmdCopyImageRegions`. It does not claim self-image
copy, overlapping copies, format reinterpretation, filtered sampling, or cube
sampling.
