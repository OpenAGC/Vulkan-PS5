# FW 5.50 R8/RG8 format qualification (2026-08-01)

## Scope

This slice consumes OpenAGC API 49 for native R8/RG8 SNORM, UINT, and SINT
images. Vulkan maps their exact layouts, sampled descriptors, color-target
classes, image views, storage eligibility, feature queries, and clear packing.
It also corrects R8/RG8 UNORM storage-image creation, which had disagreed with
the revision-frozen Eden inventory.

The expanded linear-image probe covers those eight R8/RG8 forms plus the
previous eighteen scalar/vector formats. It requires the exact feature mask,
creates sampled/storage/color-attachment/transfer images and views, clears all
26 images in one command buffer, waits on one fence for at most two seconds,
and compares every byte in all 1,664 pixels. Normalized forms require filter
and blit support; integer forms reject those claims.

This gate proves exact feature advertisement, image/view creation, native GPU
clear, and readback. Shader sampling, storage-image shader operations, and
scalar/vector attachment exports remain separate hardware gates.
