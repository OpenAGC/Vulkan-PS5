# FW 5.50 RGB9E5 image qualification — 2026-08-01

OpenAGC API 52 adds `AGC_FORMAT_RGB9E5_FLOAT` as a four-byte sampled-image
contract using gfx10.3 SQ resource format 132 and an explicit alpha-one
selector. Vulkan maps `VK_FORMAT_E5B9G9R9_UFLOAT_PACK32`, implements exact
shared-exponent clear packing, and advertises sampled/filter/transfer plus
source-blit features. Color-attachment and storage support remain disabled:
gfx10.3 requires an RB+ partial-write-mask workaround that the public runtime
does not yet qualify.

`VK_FORMAT_R32G32B32_SFLOAT` is not an image gap. Mesa's gfx10 table marks its
`32_32_32_FLOAT` encoding `buffers_only`, so Vulkan continues to reject image
creation and the Eden inventory records that deliberate boundary.
